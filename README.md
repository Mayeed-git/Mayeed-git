## 🚀 Featured projects

### ⚡ [GB Energy Data Pipeline](https://github.com/Mayeed-git/gb-energy-data-pipeline)
`Python` `Google Cloud Storage` `BigQuery` `dbt Core` `Looker Studio`

An automated daily ELT pipeline for public GB electricity and weather data.

- Ingests data into **BigQuery** every day, with **duplicate-safe reruns**
- **8 dbt models** and **16 automated data quality tests**, aligning half-hourly electricity data with hourly weather readings — including **daylight-saving transitions**
- **Three-page Looker Studio dashboard** covering carbon intensity, generation mix, weather and data freshness

### 📊 [Customer Churn & Risk Analysis](https://github.com/Mayeed-git/saas-churn-revenue-analysis)
`MySQL` `Power BI` `DAX` `Excel`

Churn, MRR and customer lifetime value analysis for a SaaS business.

- Analysed **600 customer subscriptions** and **48 months of revenue data** (synthetic dataset)
- Found **71% churn on Starter plans vs 22% on Enterprise**, informing segment-specific retention recommendations
- Built a rule-based risk score that flagged **93 of 287 active customers** — **£82.2K in monthly recurring revenue at risk**
- Communicated findings through an **interactive Power BI dashboard**

### 🗄️ [SQL Data Warehouse](https://github.com/Mayeed-git/sql-data-warehouse-project)
`SQL Server` `T-SQL` `ETL` `Dimensional Modelling`

A Medallion-style warehouse built from CRM and ERP source data.

- **Bronze → Silver → Gold** layers built from **six CRM and ERP CSV extracts**, with stored-procedure-based ingestion
- Data cleansing, deduplication, standardisation and validation in T-SQL
- **Star-schema analytical views** for customers, products and sales, with key-integrity and sales-consistency checks

### 🔎 [Web Traffic Bot Analyzer](https://github.com/Mayeed-git/bot-analyzer)
`Java` `Docker` `Behavioural Analysis`

Built during **Bright Network's Internship Experience UK (Technology)** virtual programme.

- Analysed **432K+ web requests** and identified **16 suspicious IP addresses** responsible for **8.3% of traffic**
- Containerised with Docker for reproducible execution
